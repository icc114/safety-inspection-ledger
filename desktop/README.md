# 安全检查台账 PC 0.2.2

Windows 客户端用于把 Android 检查内容持续同步并长期落地到电脑本地目录。云端只承担设备间传输，电脑资料库不是临时缓存。

## 当前功能

- 使用与 Android 相同的 Cloudflare/WebDAV 服务地址、同步空间和同步密码。
- PC 会作为一台 Windows 设备登记到 Android 的“设备管理”；管理员在手机端登出该电脑后，PC 会停止同步，直到管理员允许重新加入。
- 软件运行期间约每 2 分钟检查一次云端检查内容，也可点击“立即同步检查内容”。
- 可自行选择电脑本地资料库，例如 `D:\安全检查台账资料库`。
- 主列表点击“检查记录”、双击任意记录或按 Enter，可弹窗预览检查基本信息、检查事项、整改/复查以及照片缩略图，并可直接打开 Word 或本地文件夹。
- `检查记录.docx` 使用与 Android 直接导出 PDF 第一页一致的 A4 表单结构、字段顺序和列宽比例：标题、检查时间/地点、检查项目、检查情况/整改意见/整改记录、检查人与被检查人签名。
- 手机导出的 `.safetydata` 可直接导入 PC；PC 也能重新导出 Android/PC 通用的 v2 `.safetydata`。
- 数据包兼容 Android 当前的分块 AES-GCM v2 格式，同时仍可读取旧 v1 便携数据包。

## 本地资料结构

同步后按日期和当天顺序建立目录：

```text
安全检查台账资料库/
  2026/
    08/
      2026-08-15/
        001_0930_车棚检查_苹果园/
          检查记录.docx
          检查照片/
          整改照片/
          复查照片/
          签名/
          record.json
          同步来源.txt
```

`检查记录.docx` 是普通可编辑 Word 文件。PC 0.1.2 首次启动会把此前由系统生成且未被人工修改的旧版 Word 自动重排成与 Android PDF 第一页相同的表单版式。若用户已经手工修改 Word，软件不会覆盖人工版本，而是另存为 `检查记录-系统更新-时间.docx`。

如果移动端后来彻底删除某条记录，电脑资料库不会删除已经落地的历史文件夹，而是在该目录增加 `已从移动端删除.txt`。如果管理员之后恢复了该记录，更新版本会重新覆盖旧删除标记。

## 数据包流转

Android 的“导出数据”与 PC 的“导入手机数据包/导出手机兼容数据包”使用同一便携容器格式，因此可以按以下方式流转：

`Android A → .safetydata → PC → .safetydata → Android B`

便携包包含数据库、模板、检查记录、业务照片、签名及整改状态。PC 从云端自动同步时，则把内容进一步拆成可直接使用的本地文件夹和 Word 记录。

## 说明

PC 0.1.2 当前重点是可靠同步、长期本地归档、与 Android PDF 同版式的可编辑 Word、记录预览和 Android/PC 数据互通。PC 修改 Word 只修改本地办公文件，不会反向改写手机数据库，避免无意中把人工排版修改覆盖回现场原始记录。


## PC 0.2.2

- 删除首页左侧日历/周检侧栏，检查记录工作区占满主窗口。
- 顶部按移动端风格收敛为“立即同步 + 设置”；打开资料库、数据工具、测试连接和同步日志统一进入设置。
- 新增可查看、可导出的详细同步日志，记录每个 WebDAV 请求、HTTP 状态、耗时、快照名称和异常堆栈，但不会记录同步密码或认证令牌。
- 云端请求增加超时/临时网络错误自动重试；单个设备快照失败不会阻断其他设备快照的成功同步。
- 顶部应用图标使用超采样和高对比度绘制，在 Windows 标题栏/蓝色顶栏下更清晰。
