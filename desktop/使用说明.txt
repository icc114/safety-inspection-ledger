安全检查台账 Windows 版 3.1.0

一、打开软件

1. 请先把整个压缩包解压到一个固定文件夹，不要直接在压缩包内运行。
2. 双击“打开安全检查台账.bat”。也可以直接双击 index.html。
3. 建议使用 Windows 自带的 Microsoft Edge 或最新版 Chrome。
4. Windows 端与安卓端功能一致：可新建、修改、补录整改、横屏手写签名、管理模板、查看日历以及导出PDF。

二、启用手机与电脑自动同步

1. 软件首页点击“设置云同步”，先选择服务提供商。
2. “配套免费云服务（Cloudflare）”：打开“免费云同步服务器”文件夹部署，填写生成的 workers.dev 地址。
3. “飞牛 NAS”：在 NAS 的 Docker 中使用配套文件部署，填写 NAS 同步地址。
4. “Google Drive”：填写已授权的兼容同步网关地址，普通网盘分享链接不能用于同步。
5. 填写同步空间名称、至少8位同步密码和本设备名称，先点击“测试连接”，成功后再保存。
6. 其他安卓手机或 Windows 电脑选择相同服务提供商，填写相同地址、同步空间名称和密码即可自动恢复全部记录。
7. 已经启用同步后仍可进入“同步设置”更换服务提供商；旧服务中的数据不会自动删除。

三、离线与恢复

1. 每次填报都先写入本机；断网时仍可拍照、签名和保存。
2. 联网后软件会自动重试；也可点击“立即同步”。
3. 另一部手机修改记录后，本电脑联网会自动收到修改。
4. 并发修改不会静默覆盖，软件会保留“冲突副本”供人工确认。
5. “移入回收站”会同步到其他设备；管理员可恢复或输入同步密码彻底删除。
6. Windows 对软删除记录仍保留本机原始数据，只有管理员明确彻底删除时才清除。

四、六个月PDF归档与导出

1. 最近6个月在云端保留完整可编辑记录和照片。
2. 超过6个月且没有待整改事项的记录，会按月份和检查类型合并成PDF云端归档；系统同时保存每条记录的页码范围，以节约免费空间。
3. 手机释放本机空间后，年度或季度导出仍会从云端补齐旧PDF。
4. 按年或按季度导出时，软件先比对云端目录，再把所有日期合并成一个PDF。
5. 每条检查独立计页，例如“2026年08月11日 第1页 共2页”，下一日重新从第1页开始。
6. 如果某一日期的云端正文或PDF缺失，软件会列明日期，并停止生成不完整文件。

五、法定节假日

1. 设置云同步后，可点击“更新法定节假日”。
2. 软件每天联网检查一次并保存到本机，断网时使用缓存和内置安排。
3. 国务院尚未公布的未来年份无法提前显示，公布后再联网更新。

六、应急离线备份

首页“应急离线备份”仍可导出或导入 .csinspect 文件。云端暂不可用时，可通过U盘、数据线等方式迁移全部记录、照片、签名和模板。

七、本机数据提醒

Windows 记录保存在当前浏览器的本机存储中。不要随意清除 Edge/Chrome 的网站数据；建议保留定期离线备份，并把软件文件夹固定在同一路径。
