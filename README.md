# 安全检查台账 Android

真正独立的 Android 原生离线优先应用。包名 `cn.safetyledger.app`，当前版本 `1.2.1`（versionCode 4），最低 Android 8.0（API 26）。工程由新的 Java 17 / Android SDK 源码编译，不包含 WebView、旧 APK、DEX、旧 Manifest、旧数据库或旧软件代码。

## 当前已完成

- 首页台账中心：标题旁使用小号矢量设置图标，各页返回图标同步缩小；提供检查填报、紧凑七列月历和记录列表；有检查的日期显示黄色五角星，不再使用蓝底，国务院正式法定假日为红字。
- 筛选与分页：当日、月、季度、年度、全部，检查类型、整改状态，10/20/50/100/200 条每页；多选导出下“全选”会切换为“取消全选”，导出可选择逐条独立 PDF 或合并 PDF，合并时可按检查日期正序/倒序排列。
- 填报页通过表单内下拉框直接切换基础设施/检查模板，避免弹窗无法选择；首次建库提供可编辑的“车棚安全检查”8 项初始模板，不在 UI 代码中写死。
- 模板管理：新建、改名、改类别、启用/停用、删除；项目新增、编辑、删除、上移/下移，删除后序号自动压紧。检查保存模板快照，历史不随模板修改。
- 检查填报采用紧凑表格业务流程：前置内容只保留检查日期和检查地点；每项只选择“是/否”，“否”时必须填写现场情况、发现问题及整改要求。不再显示不适用、检查结论、独立整改意见、责任人和期限字段。
- 照片：Android 13+ 使用系统照片网格多选，旧系统回退到手机相册，不再主动打开通用文档/“安全访问”界面；导入超大原图和列表缩略图均按目标尺寸采样解码，避免照片上传后因内存占用过高退出填报页；缩略图可进入全屏预览并支持双击、双指缩放。业务照片与原始照片保存于 APP 私有媒体体系；优先读取 EXIF 原始拍摄时间、方向与 GPS，GPS 显示为“北纬/南纬、东经/西经”中文格式，缺失的元数据不会用当前填报信息伪造水印。
- 草稿：离开填报页、调用相机/相册或进入签名页时自动保存当前日期、地点、勾选和问题内容；首页记录列表中的“草稿”可点击后继续编辑，不再误入只读详情页。
- 整改闭环：存在“否”项时进入待整改；详情页补录整改情况和整改照片，并通过“整改确认：已整改完成”明确确认。确认前强制要求整改说明和至少一张整改照片。
- 三方电子签名：检查人员 1、检查人员 2、被检查人；横屏沉浸式隐藏状态栏和导航栏、5dp 圆角平滑笔迹，角色提示及清空/确认压缩到 34dp 单行工具栏，剩余区域全部用于签字；按实际画布尺寸保存 PNG，可重新查看并进入 PDF。
- 正式 A4 PDF：单条、多选、按月/季度/年度/全部合并导出；首页按参考表格固定为“日期与地点—类别—序号—检查内容及标准—是/否—现场情况/问题—整改记录—三方签名”，模板新增项目后动态调整行高和字号并保持检查表在一页，照片始终从该记录第二页开始；同一日期统一计算总页数，换日期重新从第 1 页开始。导出前校验本地媒体，缺失会明确停止。
- APP 数据备份：基础设置内可“备份到手机文件夹”或“从备份文件恢复”，通过 Android 系统文件选择器生成/选择可复制到另一手机或电脑的 `.safetydata` 文件；独立魔数和格式版本、schema 版本、SHA-256，PBKDF2-HMAC-SHA256（310,000 次）派生 AES-256-GCM 密钥；包含数据库、设置和全部业务媒体，错误密码/损坏文件/PDF 均拒绝。
- 恢复：合并恢复不覆盖相同 UUID，差异记录建立冲突副本；完整恢复保留恢复前数据库副本；跨设备恢复后重建照片与签名本地路径。
- 删除：普通删除进回收站，可恢复；永久删除要求 PBKDF2 密码并二次确认，删除本地媒体及数据库关联并写 tombstone。
- SQLite schema v1：全部业务主键 UUID，显式 `schema_migrations` 基线；记录/媒体/签名含版本与更新时间；provider-neutral 云配置、同步队列、tombstone、冲突副本、归档索引均已预留。
- 云设置：服务提供商、地址、用户名、密码、Token、同步空间、端到端加密密码；秘密使用 Android Keystore AES-GCM；测试成功/失败明确显示，失败通知栏提醒。
- 多设备基础配置：可标记“主设备（保留完整数据）”或“现场采集设备（拍照填报）”并设置设备名称，为当前手机、另一手机和 Windows 主设备的同步拓扑预留稳定字段。
- 2026 年节假日：只缓存国务院办公厅正式公布的 2026 年放假调休安排及来源；未正式公布/未缓存年份不预测。
- GitHub Actions：Java 17、Android SDK、单元测试、Lint、`assembleDebug`、中文 APK artifact。

## 尚未完成（不冒充实现）

- Cloudflare、WebDAV、飞牛 NAS、Google Drive、OneDrive、自定义 HTTP 的实际上传/下载 provider；后台自动双向同步、网络恢复自动重试、云 A 到云 B 迁移执行器。
- 云端缺失媒体/归档 PDF 的自动回下载。目前导出会检测本地缺失并明确停止，不会静默输出不完整 PDF。
- “完成且已云端验证超过 180 天”自动生成归档 PDF、释放手机空间和手动“释放本机空间”界面。schema 已含 `archive_index`，在实际 provider 可验证远端文件前保持关闭。
- 从国务院网站自动抓取并校验新的节假日公告。当前 v1 仅内置 2026 年正式公告缓存，其他年份不会预测。
- Windows 原生客户端及类似微信的电脑端后台接收目录。本仓库当前只交付 Android；UUID、版本、设备角色、`.safetydata` 和同步 envelope 已按 Windows 兼容方向设计，`.safetydata` 可先手动复制到电脑保存。
- 真机 Camera/定位/系统文件选择器的设备矩阵测试及 UI 自动化测试；当前已通过 Java 单元测试、Android Lint 和本机 Gradle 构建。
- Android 系统照片选择器可能因系统隐私策略移除相册照片的 GPS EXIF；这种情况下保留原始照片和水印接口，但不显示虚假位置。APP 直接调用相机拍摄时可用本机定位作为 EXIF 缺失时的拍摄位置后备。

## 数据升级

数据库从 v1 开始，`LedgerDatabase.onUpgrade` 是唯一 migration 入口，未来升级必须逐版执行并写入 `schema_migrations`，不得使用破坏性重建。覆盖安装且签名相同会保留 APP 私有数据库和媒体。

## 本地构建

需要 JDK 17 与 Android SDK 35：

```shell
./gradlew testDebugUnitTest lintDebug assembleDebug
```

输出：`app/build/outputs/apk/debug/app-debug.apk`。CI artifact 名称为 `安全检查台账-1.2.1.apk`。
