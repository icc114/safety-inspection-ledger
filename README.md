# 安全检查台账 Android

真正独立的 Android 原生离线优先应用。包名 `cn.safetyledger.app`，版本 `1.0.0`，最低 Android 8.0（API 26）。工程由新的 Java 17 / Android SDK 源码编译，不包含 WebView、旧 APK、DEX、旧 Manifest、旧数据库或旧软件代码。

## 当前已完成

- 首页台账中心：标题、检查填报、设置、可切换月历、记录列表；检查日期为蓝色、国务院正式法定假日为红色、调休上班为橙色。
- 筛选与分页：当日、月、季度、年度、全部，检查类型、整改状态，10/20/50/100/200 条每页；单选、多选、全选当前筛选结果、取消全选及已选数量。
- 先选择基础设施/检查模板再填报；首次建库提供可编辑的“车棚安全检查”8 项初始模板，不在 UI 代码中写死。
- 模板管理：新建、改名、改类别、启用/停用、删除；项目新增、编辑、删除、上移/下移，删除后序号自动压紧。检查保存模板快照，历史不随模板修改。
- 检查填报：日期、时间、类型、单位、地点、值班人员、检查人员 1/2、被检查人；每项合格/不合格/不适用，不合格展开问题与问题照片；结论、整改意见、责任人、期限。
- 照片：系统相机和相册；现场、问题、整改、复查四类；业务照片与原始照片保存于 APP 私有媒体体系，水印包含时间、地点及获取成功时的经纬度。
- 整改闭环：待整改 → 整改中 → 已整改完成 → 已完成；可补整改情况、整改照片、复查结果和复查照片。
- 三方电子签名：检查人员 1、检查人员 2、被检查人；横屏原生画布、粗笔迹、按实际画布尺寸保存 PNG，可重新查看并进入 PDF。
- 正式 A4 PDF：单条、多选、按月/季度/年度/全部合并导出；表格含基本信息、项目、标准、结果、问题、整改/复查、签名、四类照片；超过 8 项自动续表页，日期切换后页码重新从 1 开始。导出前校验本地媒体，缺失会明确停止。
- APP 数据备份：`.safetydata` 独立魔数和版本、schema 版本、SHA-256；PBKDF2-HMAC-SHA256（310,000 次）派生 AES-256-GCM 密钥；包含数据库和全部业务媒体，错误密码/损坏文件/PDF 均拒绝。
- 恢复：合并恢复不覆盖相同 UUID，差异记录建立冲突副本；完整恢复保留恢复前数据库副本；跨设备恢复后重建照片与签名本地路径。
- 删除：普通删除进回收站，可恢复；永久删除要求 PBKDF2 密码并二次确认，删除本地媒体及数据库关联并写 tombstone。
- SQLite schema v1：全部业务主键 UUID，显式 `schema_migrations` 基线；记录/媒体/签名含版本与更新时间；provider-neutral 云配置、同步队列、tombstone、冲突副本、归档索引均已预留。
- 云设置：服务提供商、地址、用户名、密码、Token、同步空间、端到端加密密码；秘密使用 Android Keystore AES-GCM；测试成功/失败明确显示，失败通知栏提醒。
- 2026 年节假日：只缓存国务院办公厅正式公布的 2026 年放假调休安排及来源；未正式公布/未缓存年份不预测。
- GitHub Actions：Java 17、Android SDK、单元测试、Lint、`assembleDebug`、中文 APK artifact。

## 数据升级

数据库从 v1 开始，`LedgerDatabase.onUpgrade` 是唯一 migration 入口，未来升级必须逐版执行并写入 `schema_migrations`，不得使用破坏性重建。覆盖安装且签名相同会保留 APP 私有数据库和媒体。

## 本地构建

需要 JDK 17 与 Android SDK 35：

```shell
./gradlew testDebugUnitTest lintDebug assembleDebug
```

输出：`app/build/outputs/apk/debug/app-debug.apk`。CI artifact 名称为 `安全检查台账-1.0.0.apk`。
