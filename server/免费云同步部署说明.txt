安全检查台账 v3.1.0——免费云同步部署说明

一、这是什么

本文件夹是安卓端和 Windows 端共用的免费云同步服务器。
它使用 Cloudflare Workers + D1，不创建 R2、信用卡扣费项目或付费套餐。

二、第一次部署

1. 准备一台能联网的 Windows 电脑。
2. 安装 Node.js LTS（如果电脑已经安装可以跳过）。
3. 注册或登录自己的 Cloudflare 免费账号。
4. 双击“部署免费云同步.bat”。
5. 浏览器出现 Cloudflare 授权页面时点击允许。
6. 等待脚本完成；文件夹内会生成“云同步地址.txt”。
7. 在安卓和 Windows 软件首页点击“设置云同步”，填写该 https://...workers.dev 地址。

三、第一台设备

打开软件“云同步”，服务提供商选择“配套免费云服务（Cloudflare）”，填写：
- 部署后生成的同步服务地址；
- 自己确定的同步空间名称；
- 至少8位同步密码；
- 本设备名称。

先点击“测试连接”，成功后保存。第一台连接该同步空间的设备自动成为管理员。

四、第二部手机或 Windows 电脑

选择相同服务提供商，填写相同的同步服务地址、同步空间名称和同步密码，再填写本设备名称。软件会自动连接并恢复全部云端记录。管理员可以在“设备管理”中移除丢失或停用的设备。

五、数据和费用原则

- 填报永远先保存本机，网络中断不影响现场检查。
- 表格正文、照片和签名在设备端使用 AES-GCM 加密后再上传。
- 云端只看到内部同步空间标识、检查日期、检查类型和同步状态，不能读取照片及表格正文。
- 最近6个月保留可编辑记录；符合条件的旧记录由软件生成PDF归档后上传。
- 单条云端文件上限32MB，照片很多时建议分次检查或及时在电脑保留完整备份。
- Cloudflare 免费额度有上限；本方案不会自动转入付费资源。达到免费上限时同步会暂停，本机填报仍可用。

六、重要提醒

- 同步密码无法由云端找回，请由单位管理员妥善保存。
- “仅释放本机空间”不会删除云端PDF和电脑原始记录。
- “移入回收站”可以恢复。
- “彻底删除所有设备数据”需要管理员再次输入同步密码，执行后无法恢复。
- 国务院尚未公布的未来年度节假日无法提前更新；公布后，软件联网会自动缓存最新安排。
- workers.dev 在不同网络环境中的速度可能不同；软件会自动重试，不会因此丢失本机记录。

七、更新服务器

以后收到新版服务器文件后，在新文件夹内再次双击“部署免费云同步.bat”。脚本会复用同名D1数据库并更新程序。
